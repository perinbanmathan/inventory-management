# Supermarket Inventory Management System

A C# desktop application for managing supermarket inventory.

## Overview

This project demonstrates a simple inventory management workflow using C# and .NET.

## Tech Stack

- C#
- .NET
- Windows Forms

## Project Structure

- `Program.cs` — application entry point
- `App.config` — application configuration
- `SupermarketInventoryManagementSystem.sln` — Visual Studio solution
- `SupermarketInventoryManagementSystem.csproj` — project configuration

## Getting Started

1. Open `SupermarketInventoryManagementSystem.sln` in Visual Studio.
2. Restore the project dependencies.
3. Build the solution.
4. Run the application.
